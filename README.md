# Social Media Post Analyzer

A Generative AI web application that analyzes a social media post and returns its **tone**, **intent**, **communication style**, and a concise **summary**. The application uses Google's Gemini API for text generation, Streamlit for the user interface, and Pydantic to validate structured JSON output.

## Features

- **Tone analysis** — identifies the tone conveyed by the post.
- **Intent classification** — describes the post's purpose, such as an announcement or promotion.
- **Communication style** — characterizes how the message is written.
- **Short summary** — provides a concise overview of the post.
- **Structured output** — requests JSON from Gemini and validates the response with a Pydantic model.
- **Simple web interface** — enter text and view the analysis in Streamlit.
- **API key configuration** — reads the Gemini API key from Streamlit secrets or an environment variable.

## How It Works

1. The user enters a social media post in the Streamlit interface.
2. `prompt.py` builds a prompt that asks Gemini to analyze only the supplied text and return the required JSON fields.
3. `model.py` sends the prompt to the Gemini `gemini-2.5-flash` model.
4. `parser.py` parses the model response as JSON and validates it against the `PostAnalysis` Pydantic model.
5. `app.py` displays the structured output and a breakdown of the analysis.

## Output Format

The application expects these four string fields:

```json
{
  "tone": "Enthusiastic",
  "intent": "Announce product launch",
  "communication_style": "Informative and professional",
  "summary": "The post announces an upcoming AI-powered learning platform and encourages readers to watch for updates."
}
```

The values above are an illustrative example. Actual results depend on the text submitted and the model's response.

## Setup and Run Locally

### 1. Clone the repository

```bash
git clone <YOUR_REPOSITORY_URL>
cd social-media-post-analyzer
```

Replace `<YOUR_REPOSITORY_URL>` with the URL of your Git repository.

### 2. Create and activate a virtual environment

**Windows (PowerShell):**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

**macOS / Linux:**

```bash
python -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure the Gemini API key

The application checks Streamlit secrets first and then falls back to the `GEMINI_API_KEY` environment variable.

**Option A — `.env` file**

Create a `.env` file in the project root:

```env
GEMINI_API_KEY=your_gemini_api_key
```

The provided `model.py` uses `python-dotenv` to load this file.

**Option B — Streamlit secrets**

Create `.streamlit/secrets.toml`:

```toml
GEMINI_API_KEY = "your_gemini_api_key"
```

Keep your API key private. Do not commit `.env` or `secrets.toml` to a public repository.

### 5. Start the application

```bash
streamlit run app.py
```

Streamlit will provide a local URL in the terminal. Open it in your browser, enter a post, and select **Analyze Post**.

## Example Input

```text
We are excited to launch our new AI-powered learning platform next week.
Stay tuned for more updates!
```

The application returns the post's tone, intent, communication style, and summary. Results are generated by Gemini, so wording may vary.

## Error Handling

The application checks for an empty input before sending a request. The parser also returns an error result when the model response is invalid JSON or does not match the required Pydantic schema. API configuration and generation errors are surfaced by the Streamlit interface.

## Deployment

The application can be deployed to a hosting service that supports Streamlit. For Streamlit Community Cloud, the general workflow is:

1. Push the project files to a GitHub repository.
2. Create a new app in Streamlit Community Cloud and select the repository and `app.py`.
3. Add `GEMINI_API_KEY` under the app's **Secrets** settings.
4. Deploy the app and test it with a sample post.

Deployment is not performed by this repository itself; configure the hosting service and secret separately.

## Security Notes

- Never hard-code your Gemini API key in source files.
- Do not commit `.env` or `.streamlit/secrets.toml`.
- If a key is accidentally exposed, revoke it and create a replacement.

## Limitations

- The analysis is based on the text provided; the application does not fetch or inspect posts directly from social media platforms.
- Output quality depends on the input text and Gemini's response.
- The parser validates the required fields and data structure, but it does not independently verify whether the model's interpretation is correct.
